# L7 — Multi-agent (tiny)

**Proves:** supervisor **or** handoff, and **no grant union**. Add agents only after a single loop’s failures are real ([14](../14-MULTI-AGENT-SYSTEMS/01-overview.md)).

## Runnable

`python 42-CAPSTONE-PROJECTS/labs/l07_multi_agent.py`

Handoffs as a primitive appear in the OpenAI Agents SDK docs (`SRC-OPENAI-AGENTS-SDK`). This lab does not call that SDK.

## Toy vs production-oriented

Toy: two chatbots share one service account. This lab: agent B gets `{read_kb}`, not A∪B.

## BREAK

A handoff that copies A’s `write_ticket` grant must be rejected.

## Security

Confused deputy is the distinctive risk of architecture E.
