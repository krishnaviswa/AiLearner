# L6 — NL-to-SQL (validation first)

**Proves:** parse + policy **before** any cursor. This lab never opens a database.

## Runnable

`python 42-CAPSTONE-PROJECTS/labs/l06_nl2sql.py`

## Toy vs production-oriented

Toy: `EXECUTE` model text. This lab: reject `SELECT *`, unknown tables, PII columns, missing `LIMIT`.

## BREAK

Gold includes `SELECT * FROM orders` and `SELECT ssn FROM orders` — both must fail closed.

## Security

No live warehouse. Column `ssn` is a **name** in the allowlist deny, not a real SSN.

## When not NL-to-SQL

A parameterized API or a semantic layer already answers the question ([C](../40-REFERENCE-ARCHITECTURES/C-nl2sql.md)).
