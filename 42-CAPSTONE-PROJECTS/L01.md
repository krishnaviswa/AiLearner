# L1 — Simple LLM application

**Proves:** a versioned contract and an eval of **one** call. Not an agent.

## Runnable

`python 42-CAPSTONE-PROJECTS/labs/l01_simple_llm.py`

Stub `predict()` stands in for a model. Replace later with a fetched SDK — method names **UNVERIFIED** here.

## Toy vs production-oriented

Toy: print a chat. This lab: gold keys, missing prediction **fails closed**.

## BREAK

Change gold `t2` and watch the harness name the failing case. Do not invent “92%.”

## Security

No user PII in the gold set. Prompt text is synthetic ticket subjects.

## When a deterministic function wins

If the labels are a closed enum from a form field, skip the model.
