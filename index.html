How this site flows

  1. Start — this page
  2. Map — why the lab exists, canonical architecture, sequence
  3. Foundations — tokens, one call, when not an agent, then LLM apps
  4. RAG — embeddings → store → naive → hybrid/ACL → agentic retrieve
  5. Agents — tools, MCP, orchestration, multi-agent, NL-to-SQL
  6. Eval — gold first; LLM-as-judge is a helper
  7. Security — guardrails, DLP, governance
  8. Production — reference architectures and cloud maps
  9. Labs — recent agentic assignments, hands-on ladder, simulations
  10. Reference — glossary, cheat-sheets, anti-patterns, interviews

On a concept, the pills under the title are other HTML files. Click Simple, then Medium, then Complex for the same idea (mental model → mechanism → official Microsoft / Google / AWS / Databricks maps). When not and Do stay beside those. The URL changes. This is not a dropdown that hides headings.

Every lesson lists Sources used and Further reading from 99-META/sources.yaml. Catalog: Sources and further reading.

Missing Medium/Complex/Architecture pages are skipped, not stubbed. Observability, cost, cloud maps, ref-arch A–E, the L1–L10 ladder, and cheat-sheets are on the path because those HTML files exist.
