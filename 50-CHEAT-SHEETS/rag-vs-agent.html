Cheat-sheet — RAG vs agent

Microsoft Learn: if you can write a function, do that (SRC-MS-AGENT-FRAMEWORK). This table is the lab’s durable cut.

Need Prefer First page
Answer from your corpus, one retrieve RAG 08
Same, but keywords + vectors Hybrid RAG 08 comparison
Multi-tenant / classified docs Permission-aware RAG 08 comparison
First retrieve measured-wrong, rewrite is ad hoc Agentic RAG (retrieve-as-tool) 09
Known rewrite (hyphenate SKU, add synonym) Workflow, not an agent 09 when-not
Next action unknown; tools under uncertainty Agent 10
Steps already enumerated Workflow / DAG 10 when-not
One classify / extract Structured LLM app 05
Known lookup SQL / API / semantic layer 15 when-not 
flowchart TD
  N[Need an answer] --> C{Corpus or tools?}
  C -->|corpus| R{One retrieve enough?}
  R -->|yes + ACL| RAG[Permission-aware RAG]
  R -->|measured miss| AR[Agentic RAG]
  C -->|tools / unknown next hop| A{Function enough?}
  A -->|yes| F[Function]
  A -->|no, steps known| W[Workflow]
  A -->|no, steps unknown| AG[Agent + IAM + eval]

When not

Do not wrap a single always-called retrieve in an “agent.” That is RAG with extra blast radius (LLM03).
