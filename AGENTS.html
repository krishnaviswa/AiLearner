AI Engineering Knowledge Lab — agent instructions

This repository is an AI Engineering Knowledge Repository and Interactive Learning Lab. It is not a dumping ground for tutorials.

Canonical operating prompt: AI_Engineering_Knowledge_Repository_Master_Prompt.md.

Before doing anything

  1. Read 99-META/GATE-STATUS.md.
  2. Obey the current gate. While owner_policy is standing auto-advance through Gate 10, start the next gate only after QA chair PASS (not a human named-gate message). If that policy is unset, do not start the next gate unless the user names it and explicitly approves.
  3. Prefer files already in 00-MASTER-MAP/ and 99-META/ over generating new overviews.

Markdown is the source of truth. Learner-facing HTML is generated by python app/tools/render-pages.py. Do not dual-write HTML by hand. Do not HTML-ize .cursor/ or the master prompt.

How this repo is supposed to work

  • Teach progressively (simple → production → principal). Cover all major agent flavors, not only RAG.
  • Bake durable knowledge into local artifacts. Use web research for volatile APIs, SKUs, versions, and pricing.
  • Never invent APIs, prices, or capabilities. Label UNVERIFIED.
  • Never create empty concept files. Use 99-META/templates/concept.md only when writing real content.
  • Quality marks: PASS / FAIL / NEEDS REVIEW. A gate advances only on QA chair PASS.

Skills

  • Adding or expanding a concept: .cursor/skills/contribute-concept/SKILL.md
  • Closing or advancing a gate: .cursor/skills/advance-gate/SKILL.md
  • QA committee and scorecard: .cursor/skills/qa-gate/SKILL.md

Open the lab

From the repo root: python -m http.server 8766 (or .\serve-lab.ps1) then open http://127.0.0.1:8766/index.html. Do not use port 8000 — that is often another API. Theme is Dark | Light (localStorage key lab-theme).
