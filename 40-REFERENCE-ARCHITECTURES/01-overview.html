Five teaching shapes from Gate 0. Each page: distinctive risk, one sequence, when-not. Not a full BOM (frontend through DR). Vendor mappings stay in 26.

Shared failure-first list

Timeout / search down / tool wrong / loops / injection / bad retrieve / bad SQL / PII leak / cost explosion / context overflow / model regression / stale index. For each: detect, mitigate, fallback, recover, alert, test — ops.

What should I remember?

Pick the architecture by risk, not by how impressive the demo looks.
